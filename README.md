## Проект лабораторной №4 — EnglishMate

**EnglishMate** — Telegram-бот для изучения английского языка с использованием искусственного интеллекта.

В лабораторной работе №4 разработана модель облачной инфраструктуры приложения для трёх стадий развития:

- MVP — 100 активных пользователей в месяц.
- Партнёрское тестирование — 1 000 пользователей.
- Продакшен — 10 000 пользователей.

Для каждого этапа спроектирована архитектура и рассчитаны ориентировочные затраты на эксплуатацию.
